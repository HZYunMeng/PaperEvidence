# NLP 论文：固定代码检查与原文浏览

2026 年 10 月 9 日，使用尚未参与此前解析器开发的两篇 NLP 论文扩充检查。下载 PDF、制作标注前，记录了 `eb7f6f10d258d3cae87e9fdec938e904d0a46b89` 的解析、布局、分块、检索、表格和引用校验模块 SHA256。本轮保留这些模块，改动集中在评测工具和证据浏览。结果不是经过独立人工标注或具有统计代表性的测试基准。

## 来源与协议

| 论文 | 官方出处 | PDF 页数 | 独立事实 |
| --- | --- | --- | --- |
| Devlin、Chang、Lee、Toutanova，2019，BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding | [ACL Anthology / NAACL-HLT](https://aclanthology.org/N19-1423/) | 16 | 4 |
| Vaswani 等，2017，Attention Is All You Need | [NeurIPS 官方会议论文集](https://papers.nips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html) | 11 | 4 |

每篇选两个正文事实、两个表格事实，分别配英文和中文问题，共八个独立事实、16 道可回答题、八道配对表格题。另有两个无答案探针，仍只记录候选数，不衡量拒答或幻觉。标注由 agent 阅读相关完整 PDF 页与渲染图、核对字符区域后制作，尚未独立人工复核。短引文和来源区域只用于指标，不进入检索输入。

BERT 表 1 含任务名与训练样本数量两行，方法名有下标。Transformer 表 2 含 BLEU、Training Cost 分组和重复的 EN-DE / EN-FR 标签。标注保留原始行名、列名和必要的 `column_group`。目前引用适配器没有多层表头的几何结构；带 `column_group` 的目标一律计为单元格不可用，不能仅凭同名底层列通过指标。

清单记录官方 URL、作者、年份和下载 PDF 的固定 SHA256。ACL 页面声明 2016 年起的材料采用 CC-BY-4.0；NeurIPS 文件仅供本地研究下载，这里不主张其再分发授权。源码只含出处、短标注及结果，不包含下载的论文或完整渲染页；代码 MIT 许可不覆盖论文。

## 复现

在项目根目录，准备基础依赖后运行：

```bash
python scripts/fetch_real_papers.py --dataset eval/nlp
# 不需要模型权重：
python eval/real_eval.py --dataset eval/nlp --retrievers bm25 --out eval/nlp/bm25-results.json
# 准备可选语义依赖和固定 E5 权重后：
python eval/real_eval.py --dataset eval/nlp
```

`--data-dir` 可指定 PDF 所在目录；默认下载至 `data/real-papers`。`--out` 默认写入所选数据集目录的 `results.json`。下载失败、PDF 非法或哈希变化时停止；已有文件只有验证成功才复用。若 `protocol.json` 包含代码哈希，评测会强制核对，代码变更时拒绝冒充原检查。后续修改解析器时，请复制为新的、注明开发用途的数据集协议和结果目录，保留原记录；这些题一旦用于调参，就成为开发题。

检索器保持同一篇论文、同一批 1400 字符目标分块、k=3。CPU 实际加载固定版本 multilingual-e5-small，无生成模型或付费 API 调用。评测先检查 PDF 标注区域的原文，再区分完整索引是否有目标、是否有可绑定单元格、前三候选是否找回。逐题结果保留失败及候选的页码与分数类型。

## 结果与边界

| 检索器 | 英文证据 | 中文证据 | 全部证据 | 目标单元格 |
| --- | --- | --- | --- | --- |
| BM25 | 6/8 | 3/8 | 9/16（56.25%） | 0/8 |
| E5 语义 | 3/8 | 3/8 | 6/16（37.5%） | 0/8 |
| BM25 + E5 融合 | 5/8 | 4/8 | 9/16（56.25%） | 0/8 |

16 道题的短引文及源区域在完整索引中可找到；四个独立表格事实均没有可靠行列绑定。八道配对表格题不是八个独立表格事实。证据召回仍只说明片段中存在标注文字和区域，不证明对应方法、单位、分组或问题理解正确。

- **BERT 表 1** 没有成为结构化表格，宽表被正文阅读顺序启发式拆开，目标数字所在片段丢失了左侧方法名。四道表格题三种检索器均未找回正确片段。正文的语义检索也有遗漏，不能归咎于表格一个模块。
- **Transformer 表 2** 保留了文字与数字，但多层表头没有恢复为结构化单元格。三种检索器都能找回两项表格目标所在的文字区域，仍不能导出可信的行名、分组表头和数值绑定。
- 中文问题、英文原文中的词形和符号仍会影响候选排名。融合在这批题上没有提高整体召回，保持 BM25 默认。

下一次解析改动优先检验宽表边界与多层表头。需要另留新论文用于验收，不能在修好这些题后继续称其独立检查。

## 现在如何核查失败

下载完成后，侧栏会自动列出校验过哈希的真实论文。打开“逐页浏览论文（无需提问）”，选择 PDF 页码，可直接看完整原文，也可查看本页全部、正文或已识别表格片段。即使检索无命中或整篇没有可索引文字，仍能查看 PDF。扫描件只能浏览，尚无 OCR。

片段浏览与检索结果共享单元格检查，避免两套显示规则。可导出原文片段、来源块坐标，或可靠单元格的行名、表头和值；后者只显示当前行可绑定的列。正文片段导出不声称任意逐字坐标或结论支持。表格筛选数量是已识别结构数量，不代表论文实际表格数。
