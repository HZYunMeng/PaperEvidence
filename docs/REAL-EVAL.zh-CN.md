# 真实论文开发集：结果与失败案例

开发集于 2026 年 10 月 8–9 日建立，当前结果来自 10 月 9 日的 v0.4.0 几何解析与按行分块。没有调用生成模型或付费 API，没有评测答案准确率或幻觉率。

## 论文与标注

| 论文与作者 | 出处 | PDF 页数 |
| --- | --- | --- |
| Chen、Kornblith、Norouzi、Hinton，2020，A Simple Framework for Contrastive Learning of Visual Representations | [PMLR 119](https://proceedings.mlr.press/v119/chen20j.html) | 11 |
| Radford 等，2021，Learning Transferable Visual Models From Natural Language Supervision | [PMLR 139](https://proceedings.mlr.press/v139/radford21a.html) | 16 |
| Tan、Le，2019，EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks | [PMLR 97](https://proceedings.mlr.press/v97/tan19a.html) | 10 |

每篇选 4 个事实，各配英文与中文问题，共 12 个事实、24 道可回答题；其中 6 个事实来自表格。另有 3 个无答案探针，仅记录返回候选数。语言配对问题不算独立样本。

标注初稿由 agent 阅读相关完整 PDF 页、查看渲染图并核对原文坐标后制作，**还没有独立人工复核**。每题记录参考答案、PDF 页码、短引文和源区域；表格题额外记录行名、表头及必要的架构上下文。页码是 PDF 从 1 开始的页序，不是会议论文页码。

[标注](../eval/real/qa.json)和[论文清单](../eval/real/papers.json)可检查；清单保留作者、题名、年份、官方 URL 与 PDF SHA256。PMLR 的[出版协议](https://proceedings.mlr.press/pmlr-license-agreement.html)指定 CC-BY-4.0，原论文版权仍归作者。源码包只含出处和短标注，不含下载的 PDF 或渲染页。引用这些事实时保留论文出处。

## 复现与指标

准备基础依赖、可选语义依赖和本地 E5 权重后，在项目根目录运行：

```bash
python scripts/fetch_real_papers.py
python eval/real_eval.py
# 只检查关键词检索时，无需 E5 权重：
python eval/real_eval.py --retrievers bm25 --out eval/real/bm25-results.json
```

下载脚本校验固定哈希，出版社文件变化时停止。评测先直接检查 PDF 标注区域是否有对应引文，再运行解析和检索。参考答案与标注只进入指标计算，没有作为检索输入。

三个检索器使用同一篇论文、同一解析器、1400 字符目标分块（长表格只在行之间拆分，重复表头与表注；单行过长则完整保留）、top-k=3，不跨论文混检，不使用重排。E5 使用固定提交 `614241f622f53c4eeff9890bdc4f31cfecc418b3` 和 CPU 推理。评测重新生成向量，结果记录代码、数据、标注、模型版本和耗时。

证据召回要求正确页码、引文出现，以及片段来源区域覆盖标注区域中心。短引文和区域条件仍然较粗，不能证明结论、单位、方法或实验设置理解正确。单元格召回另要求解析行名、表头、值与来源区域正确，必要时也检查架构上下文。

## 当前结果

| 检索器 | 英文证据召回 | 中文证据召回 | 全部证据召回 | 目标单元格召回 |
| --- | --- | --- | --- | --- |
| BM25 | 11/12 | 7/12 | 18/24（75.0%） | 10/12 |
| E5 语义 | 6/12 | 3/12 | 9/24（37.5%） | 7/12 |
| BM25 + E5 融合 | 9/12 | 5/12 | 14/24（58.3%） | 9/12 |

24 个目标原文位置都在完整索引中，六个独立表格事实均已有可绑定行名、表头与值。12 道表格题是六个事实的语言配对，不能说成十二个独立成功样本。BM25 仍是这批题的最好基线，因此默认检索方式不变。`efficientnet-b0-top1-en` 和 `efficientnet-b7-params-zh` 在全索引中有可绑定单元格，但没有被 BM25 的前三候选找回，说明解析可用与检索成功仍需分开计算。

[完整逐题结果](../eval/real/results.json)同时记录成功和失败、候选页码、分数类型、耗时、目标是否已在索引中，以及单元格是否已可用。

## 本轮恢复与剩余失败

- 常见双栏：从文字坐标检测重复出现的中部空白，分左右栏读取，宽标题和跨栏表格切分阅读区域；分块不跨列拼接。
- 横线表格：至少三条对齐横线、附近表注、可辨认表头和至少两行数字数据共同约束候选；用数据行的共同空白推断列，整词分配到列，单元格坐标绑定实际字符。分组标题保留但不能作为数值单元格。连字展开只保留一次物理字符。
- 长表格：只在完整行之间拆分，重复原表头和表注；来源框仅包含该片段实际保留的表头与行，不能用整张表的区域替遗漏行通过指标。`efficientnet-b7-params-en` 现在被 BM25 找回，但语义与融合仍遗漏。
- `clip-layers-zh`：三种检索器仍都未找回正确正文区域，主题相近的实验段落仍会干扰。
- `clip-imagenet-zh`：BM25 能命中表格，语义与融合仍遗漏；跨语言检索没有在真实开发题上普遍优于关键词。

未使用论文题名、预期答案、标注坐标或标注标签作为解析规则；这些只进入指标计算。几何规则需要[独立论文检验](PARSER.zh-CN.md)，不能据当前六个事实宣称通用复杂表格解析已解决。

## 下一轮验收

六个已知表格事实已绑定来源；下一轮优先扩充独立论文和人工复核。扫描件、三栏、多层表头、跨页表格、公式与图内文字仍需更强解析器；比较解析器时保持检索和指标不变。

这三篇论文已用于开发，不作为保留测试集。让用户或另一位标注者复核 12 个事实，再选择独立论文验证。加入行交换、缺失证据和单位错误等扰动时，同时报告覆盖率、错误拒答和错误回答。

固定代码后的两篇 NLP 扩充检查已经完成，包含未能绑定的表格事实。结果与限制见 [NLP 检查报告](NLP-EVAL.zh-CN.md)；本页三篇开发集的历史结果保留。
