# 几何解析器的接口与边界

v0.5.0 继续使用文本型 PDF 和固定版本的 pdfplumber，不增加 OCR 或布局模型权重。实现位于 `paper_evidence/header_tables.py`、`layout.py`、`parsing.py` 和 `chunking.py`；文字坐标和规则的能力边界参见 [pdfplumber 官方说明](https://github.com/jsvine/pdfplumber#extracting-text)。

## 阅读顺序

先识别可接受的表格，再按字符中心从正文中排除对应区域，避免一条横跨两栏的文本行同时吞掉邻栏内容。对左右两侧都有足够文字的行，检测反复出现的中部空白。单侧短行不稀释检测比例；支持不足时保留原行提取顺序。

有可靠栏间空白时，将同一行两侧文字分开。宽标题和跨栏表格把页面分成阅读区域，各区域先读左栏，再读右栏。Block 的 `flow` 字段记录区域与列，分块遇到 flow 改变时停止合并。单栏保持自上而下顺序。

这只能处理常见双栏。三栏、侧注、异形绕图文字、跨栏段落与正文基线不齐仍可能恢复错误。检测到两栏也不证明整页阅读顺序正确。当前章节识别仍是常见标题规则，许多实际小节会落在 `Front matter`。

## 横线表格

候选需要至少三条端点对齐横线、附近的表注和至少两行有效数字数据。优先用首条内部整宽横线划分表头带与数据带；按字符高度与相邻距离吸收方法名下标。数字开头的表头备注单独保留，不冒充数据行。

底层标签之间建立列边界。上层分组必须由附近的部分横线覆盖至少两个底层列，且关系唯一；保存父级和叶子标签各自的真实字符框。支持清晰的两层分组，更深嵌套、无分组横线、归属有歧义时回退。没有首列标题且数字位于首个可见指标下方时，不将该指标错当行名，交由旧的共同空白规则提取。

空白和跨列数据保留文本但坐标为 `None`；不能作为单个数值引用。完整分组路径参与查表与评测。跨列训练开销、科学记数法的算术含义、单位与实验条件不自动解释。整表几何识别成功不证明语义正确，仍需看 PDF 原文。

原有共同水平空白的单层横线提取与网格提取保留为补充。全无边框、无表注、跨页拼接和复杂表头仍未可靠处理。重复行名保留可用的文字来源上下文。单元格框来自字符，连字按物理字符去重，不伪造网格或精确语义支持。

## 长表格分块

结构化表格超过目标 1400 字符时，只在完整行之间拆分。各片段重复原表头和表注，并携带当前分组说明。单行超过预算时完整保留，不截掉尾部单元格。

每个片段的行号从自己的表头开始，生成模型和界面使用这个局部行号。表格来源框只包含该片段实际保留的行和表头，不能借完整表格的大区域为遗漏行提供证据。单元格与源 PDF 的坐标保持不变。没有结构化行的超长文本或表格仍可能超过字符目标。

## 数据兼容与缓存

JSON 索引使用 schema 3，TableData 保存 `header_paths` 和 `header_notes`。schema 1/2 仍能加载，缺失的元数据取空值，不能补造父级来源坐标。旧索引需要重新导入 PDF 才能获得新解析结果。

Streamlit 导入缓存和问答配置包含工程版本。升级后原问答结果清除；修改解析模块后应重启服务再验收，避免 Python 已加载模块或 Streamlit 缓存仍使用旧实现。

## 验证范围

单元测试用与论文标注无关的虚构内容覆盖列间不混读、长短栏、单栏保留、横线表格、受支持分组表头、拒绝无分组横线的复杂表头、无名称行表头回退、无表注回退、越界图形、重复行上下文、连字与长表格来源框。五篇真实论文相关完整页与单元格高亮已目视核对。

真实结果与未解决的失败见 [开发集报告](REAL-EVAL.zh-CN.md)。这批论文已参与开发；需要新论文与独立标注者复核，才能判断通用能力。没有真实生成答案准确率、幻觉率或统计显著结论。
